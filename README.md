# ai-frontend

This is an AI frontend project.

## Tech Stack
- React
- TypeScript
- Vite

## Environment
- Node.js: v22.19.0
- npm: 10.8.3

## Run Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

After startup, open the local URL shown in the terminal, usually `http://localhost:5173`.
